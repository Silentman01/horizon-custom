# Run Product

Turn one competitor product URL into a launch-ready product: first a Step Alpha intelligence dossier, then brand, then our own adapted product page, home page, policies, product images, page media, ad creatives and ad copy — studying the competitor's winning formula and building a distinctly different shop that uses the same conversion principles. The **coordinator** (you) owns decisions, gates, Brandsearch calls, git/Shopify pushes and the final report; **two Opus 5.5 leads (low effort)** run the Store and Growth streams and direct cheap **Sonnet/Haiku workers** for the heavy parallel work; **copywriting and product-page agents always run on Opus 4.6** ([16 §1](references/16-orchestration.md#1-orchestration-model-coordinator--2-opus-leads--cheap-workers)).

This workflow was distilled from a real run (brand *Noxis*, cloning plaims.com headlight glasses). Every rule in `references/00-operator-rules.md` exists because the operator corrected it once — read it before anything else, every run.

**This file is the index.** Run the phases in order (streams inside a phase run in parallel), open the linked reference before each step, tick the done-checklist at the end. All detail lives in the linked files; nothing here replaces them.
